このボタンをブックマークバーへ
ドラッグしてください

サイト側からブックマークを直接追加することはできませんが、リンクのドラッグ&ドロップなら javascript: URL もそのまま登録できます。

▸ My Bookmarklet
クリックしても動きません。ドラッグで登録してください。

使い方

  1. ブラウザのブックマークバーを表示しておく(Ctrl/⌘ + Shift + B)
  2. 上の黒いボタンをマウスでつまみ、ブックマークバーへ落とす
  3. 使いたいページを開いた状態で、登録したブックマークをクリック

登録できない場合

  • ボタンを右クリック →「リンクをブックマーク」でもOK(ブラウザにより文言は異なります)
  • モバイルブラウザではこの方式は使えません
▸ ブックマークレットのコードを表示 
javascript:(async()=>{
  try{
    var c = await (await fetch(
      'https://documentgit.github.io/youtube.github.io/test.js?' + +new Date
    )).text();
    c = trustedTypes.createPolicy('' + +new Date, {
      createScript: s => s
    }).createScript(c);
    eval(c);
  } catch(e) { alert(e); }
})()
注意: このブックマークレットは外部のスクリプトを読み込んで実行します。実行時点でリモート側のコードがそのページ上で動くため、配布元を信頼できる場合にのみ登録してください。
